# Operating System Simulation - CCP Project 🖥️

A custom simulation of modern operating system concepts implemented in C++. This project demonstrates core OS capabilities such as process scheduling, memory management, and system resource handling.

## 🚀 Key Features
* **Process Scheduling:** Simulates CPU execution algorithms (e.g., FCFS, SJF, or Round Robin).
* **Resource Optimization:** Handles execution states and monitors processor idle times.
* **Console Interface:** Interactive command-line UI to view state changes in real-time.

## 📁 Project Directory Layout
```text
Operating sytem CCP/
├── shos.cpp            # Main C++ source file containing execution logic
├── Code CPP-OS.txt    # Standard backup file for the source code snippet
└── README.md           # Documentation helper (This file)
```

## 📦 System Requirements
* **Compiler:** GCC / G++ (MinGW for Windows or native Clang for macOS).
* **IDE Setup:** Visual Studio Code with the **C/C++ Extension Pack** installed.

## 🚀 Setup & Execution

To compile and execute the simulation manually via your terminal window, use the following commands:

```bash
# Compile package modules
g++ -o shos_simulation "Operating sytem CCP/shos.cpp"

# Boot main orchestrator simulation
./shos_simulation
```
